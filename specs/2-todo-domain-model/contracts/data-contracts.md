# Data Contracts: Todo Domain Model

## Todo Entity Data Contract

### Todo Object Structure

```json
{
  "id": {
    "type": "integer",
    "required": true,
    "validation": {
      "unique": true,
      "positive": true
    },
    "description": "Unique identifier for the todo item"
  },
  "title": {
    "type": "string",
    "required": true,
    "validation": {
      "min_length": 1,
      "not_null": true,
      "not_empty": true
    },
    "description": "The task description"
  },
  "description": {
    "type": "string",
    "required": false,
    "nullable": true,
    "validation": {
      "max_length": 1000
    },
    "description": "Additional details about the task"
  },
  "created_at": {
    "type": "datetime",
    "required": true,
    "format": "ISO 8601",
    "validation": {
      "timestamp": true
    },
    "description": "Timestamp when task was created"
  },
  "completed": {
    "type": "boolean",
    "required": true,
    "default": false,
    "validation": {
      "boolean_type": true
    },
    "description": "Indicates completion status"
  },
  "updated_at": {
    "type": "datetime",
    "required": true,
    "format": "ISO 8601",
    "validation": {
      "timestamp": true
    },
    "description": "Timestamp when task was last modified"
  }
}
```

### Todo Validation Rules

1. **Title Validation**:
   - Must be a non-empty string
   - Minimum length: 1 character
   - Cannot be null or undefined

2. **ID Validation**:
   - Must be a positive integer
   - Must be unique within the application
   - Auto-generated by the system

3. **Completed Status Validation**:
   - Must be a boolean value
   - Default value: false
   - Cannot be null

4. **Timestamp Validation**:
   - Must follow ISO 8601 format
   - `created_at` is set at creation time
   - `updated_at` is updated when the todo is modified

## TodoStorage Data Contract

### Storage Structure

```json
{
  "todos": {
    "type": "dictionary",
    "key_type": "integer",
    "value_type": "Todo",
    "required": true,
    "description": "Dictionary mapping IDs to Todo objects for O(1) lookup"
  },
  "next_id": {
    "type": "integer",
    "required": true,
    "validation": {
      "positive": true
    },
    "description": "Counter for generating unique IDs"
  }
}
```

### Storage Operations Input/Output Contracts

#### Add Todo Input Contract
```json
{
  "input": "Todo object",
  "validation": {
    "required_fields_present": true,
    "title_not_empty": true
  },
  "output": "Todo object with assigned ID",
  "error_conditions": [
    "Invalid Todo object",
    "Missing required fields"
  ]
}
```

#### Get Todo Input Contract
```json
{
  "input": {
    "todo_id": {
      "type": "integer",
      "required": true,
      "validation": {
        "positive": true
      }
    }
  },
  "output": "Todo object or null",
  "error_conditions": [
    "Invalid todo_id format"
  ]
}
```

#### Update Todo Input Contract
```json
{
  "input": {
    "todo_id": {
      "type": "integer",
      "required": true,
      "validation": {
        "positive": true
      }
    },
    "title": {
      "type": "string",
      "required": false,
      "validation": {
        "min_length": 1,
        "not_empty": true
      }
    },
    "description": {
      "type": "string",
      "required": false
    },
    "completed": {
      "type": "boolean",
      "required": false
    }
  },
  "output": "Updated Todo object or null",
  "error_conditions": [
    "Todo not found",
    "Invalid todo_id",
    "Invalid field values"
  ]

```

#### Delete Todo Input Contract

## TodoIdGenerator Data Contract

### ID Generator Structure

```json
{
  "current_id": {
    "type": "integer",
    "required": true,
    "validation": {
      "positive": true
    },
    "description": "The current ID value for generation"
  }
}
```

### ID Generation Contract
```json
{
  "generate_id": {
    "input": "none",
    "output": "positive integer",
    "side_effects": ["increments current_id"],
    "validation": {
      "uniqueness": true,
      "positive": true
    }
  },
  "reset": {
    "input": "none",
    "output": "none",
    "side_effects": ["resets current_id to initial value"]
  }
}
```
